# V0.1 Research Scope

## Core question

Can persistent executable artifacts act as cumulative culture for self-directed LLM agents across individual turnover when private episodic memory is not inherited?

## Experimental families

- **P** — private memory
- **T** — private memory + persistent textual culture + social interaction
- **E** — private memory + executable persistent artifacts
- **ES** — executable culture + textual culture + social interaction
- **RIL** — compute-matched repeated individual learning control

## Primary hypotheses

1. **Executable inheritance:** executable Git artifacts improve functional capability retention after turnover under matched compute.
2. **Social reuse:** social interaction reduces onboarding cost and redundant implementation when executable artifacts are available.
3. **Cultural resilience:** executable culture reduces capability loss and recovery time after creator removal or artifact/dependency shocks.

## V0.1 exclusion rule

A feature is excluded from V0.1 unless it is required to test the hypotheses above or to provide a safe, replayable, reproducible runtime.

Therefore V0.1 does not initially include detailed disease simulation, marriage, reproduction, genetics, unrestricted public internet write, autonomous public GitHub writes, model-weight self-modification, or a complex 2D life-simulation UI.

## M0

M0 establishes the deterministic experimental substrate before any model is connected:

- immutable manifest
- identical initial agents
- deterministic identifiers
- monotonic event ordering
- event reducer
- snapshot/restore
- event replay
- canonical state hash
- CI regression gate
